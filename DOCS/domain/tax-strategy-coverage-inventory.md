# Tax strategy coverage inventory

**Last source verification: 2026-07-29.**

This inventory sets the strongest claim an implementation cockpit may make from the public
RetireGolden engine today. It is a claim-control document, not a list of everything the tax law
permits. A strategy can appear in a cockpit only to the extent that the shipped model, cited rule
source, and linked tests support the wording in **Allowed cockpit-v1 claim**. “Partial” means the
engine can support a narrower planning claim, not an execution-ready instruction.

All results remain planning-grade estimates. They do not prepare a return, establish eligibility,
select a custodian transaction, or replace review by the client's tax and legal professionals.
Current-year parameters and primary-source links are maintained in the
[domain rules reference](domain-rules-reference.md).

## How cockpit code should use this inventory

1. Preserve the exact wording boundary in the **Allowed cockpit-v1 claim** column or use narrower
   language.
2. Carry the applicable limitation into the evaluation and any handoff artifact; a footnote hidden
   elsewhere is not enough for an action amount.
3. Suppress an action when its prerequisite is open. A modeled annual household amount is not
   evidence for a person, account, custodian, charity, security lot, deadline, or tax form.
4. Keep the calculation result separate from an advisor's later adoption, annotation, and
   professional-confirmation record.
5. Add source and test evidence here before broadening a claim. The absence of a failing test does
   not establish coverage.
