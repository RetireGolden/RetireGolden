## 4. `survival-hazard-from-expectancy-multiplier`

**Claim consistency:** Matches `hazardForExpectancyMultiplier(age, sex, m)`: bisection on hazard power `h` so adjusted expectancy `= m ×` SSA baseline; `m=1` ⇒ `~1`; proportional hazards `p^h`.

**Recomputation (`m=1`, `h=1`):**

At `h=1`, adjusted survival `p^1 = p` for every year ⇒  
`E_h = 0.5 + Σ S(t) = 17.48` (unchanged from SSA baseline at age 65).

Equation `E_h − m·17.48 = 0` ⇒ `17.48 − 17.48 = 0` ⇒ root **`h = 1`** exactly (no bisection iteration needed).

**Match:** **yes** (`h ≈ 1`, adjusted expectancy `17.48`).

**Tolerance (`1e-6` on `h`):** Defensible as a stand-in for an unspecified bisection stop; for this identity case the true root is exactly `1`, so `1e-6` is loose but not misleading.

**Stochastic/solver note:** **Trivial identity branch only.** Example does **not** exercise bisection convergence, monotonicity search, or clamping. It validates the definition at `m=1`, not the solver.

**Wrong readings:** Qualitative arguments for `m=0.8` / inverted hazard direction are logically consistent with the signature comments (`m < 1` = shorter expectancy; `h > 1` = worse health).

**Verdict:** **approve with a note** (identity case is correct but does not exercise the solver; acceptable as a degenerate oracle, not as bisection coverage).
