The test that cycles `KPERS`, `US-FERS`, `KS-WASHBURN`, and an invalid code over IRA and employer rows confirms this faulty invariant rather than the statute. A separate $24,000 KPERS public-pension fixture correctly shows a $24,000 named-versus-unnamed difference, but it does not test the Washburn employer-plan case. The record's “whatever code they carry” statement overclaims; retain materiality/warning where an employer row can be a named plan, or model plan identity in a way that preserves Washburn's subtraction.
